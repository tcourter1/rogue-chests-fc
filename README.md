# Rogue Chests FC

Rogue Chests FC is a RuneLite plugin built to help support and organize the Rogue Chests Friends Chat. It includes a Staff Mode with tools for monitoring FC activity, nearby players, equipment, and other moderation-related information, as well as a Thiever Mode focused on safety and quality-of-life features for players thieving Rogue Chests. The goal of the project is to keep the FC easier to manage while giving members a few useful tools for safer, smoother trips.
